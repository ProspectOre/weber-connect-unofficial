# 3.3.0rc1: controller-family beta

The broader beta now uses the 3.3 version line. Stable 3.2.2 is a separate
maintenance hotfix from 3.2.1 and does not include this controller-family work.

This candidate preserves RC6 runtime behavior. Only the version manifest changes;
the normalized runtime fingerprint is unchanged. Cloud sends permit only empty
status/capability reads (`0x05`, `0x07`, `0x0E`), with no settings timestamps or
program-detail requests. Dependencies remain on the beta's websockets 17.1.

## Evidence and limits

New automated and physical receipts bind this candidate. Exact-head CI and
canonical regular review are required before publication as a prerelease.
The physical receipt remains pending with no inherited verified gates.

The [RC6 live observation](3.2.2rc6-live-observation.json) summarizes its published
`rc6-live-proof.json` release asset and records that asset’s SHA-256. It describes
a separate targeted trial on a controller
reporting firmware `2.0.3_7398`: app-closed readings and automatic recovery
were observed after owner-controlled power cycling and a change to Probe 2.
The trial did not independently time power-on latency, test actual token expiry,
capture on-wire requests or qualify other controller families. That historical
receipt stays bound to RC6 and is not a new RC1 hardware acceptance claim.
The older RC6 candidate plans remain prepublication snapshots; this later targeted
observation does not complete their full physical matrix.

Before stable promotion, complete the repository's full exact-runtime physical
matrix and one-hour endurance run. SmokeFire cooking-time gaps, Genesis/SiLabs
pairing, portable accessories and the remaining families need their own hardware
results, as recorded in the [product matrix](../product-compatibility.md).

Use the latest stable release for the existing stable feature set. Use this
prerelease only for the controller trials described in its issue and readiness
records. Keep existing entries and entities when changing versions; restart HA
and verify the loaded version.
