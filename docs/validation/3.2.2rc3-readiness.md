## Hardware trial

Record the exact model, firmware, Home Assistant and integration versions,
adapter or proxy, and app platform. For each product, check discovery,
physical pairing, cloud association, fresh cooking/probe readings, app
coexistence, restart/recovery and stable entity identities. Include both a
success and the last reached stage on failure. A valid new framing shape needs
sanitized structural evidence and a regression fixture before it is accepted.

Do not post device identifiers, addresses, credentials, raw packets or
unredacted diagnostics. Use the integration's support report for a failed
trial. No remote control or unauthenticated Bluetooth telemetry is enabled.

For rollback, select **v3.2.1** in HACS and restart Home Assistant. Keep the
existing config entry and entities. A stable release needs a complete physical
acceptance run on the exact candidate; automated CI cannot replace that run.
