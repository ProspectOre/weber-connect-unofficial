## Limits and release decision

These results cover one hub, firmware and installation. Other models, firmware,
regions and Bluetooth adapters remain untested. The earlier baseline outage's
cause remains unknown; the current candidate's successful endurance run does
not establish causation for that historical event.

The Activity recording exclusion is an owner-selected Home Assistant
configuration change, not an automatic integration migration. It stops future
history for the timestamp sensor while retaining its live value and other
entities' history. Existing records remain until normal retention removes them.

Publish 3.2.0 only from the final reviewed commit after required CI and review
pass. Runtime changes require repeating the affected acceptance checks; the exact
Bluetooth-only transition above preserves prior endurance provenance. Do not
relabel an earlier run as a new candidate pass.
