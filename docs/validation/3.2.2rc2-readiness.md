# 3.2.2rc2: Genesis pairing hardware trial

This candidate also includes bounded pairing/TLV processing and exact appliance
association checks from security PR #63. Hardware validation remains pending.

This is a prerelease for [issue 65](https://github.com/ProspectOre/weber-connect-unofficial/issues/65).
It fixes the required/optional GATT channel assumptions and reconnect cache
handling. It does not yet establish Genesis compatibility or a different frame
format. Stable 3.2.1 remains the rollback version.

## Installation and validation

1. In HACS, open Weber Connect Unofficial, select **Redownload**, choose a
   different version, and select **v3.2.2rc2**. Enable prerelease versions if
   needed. Restart Home Assistant, then confirm the support report says
   `integration_version: 3.2.2rc2`.
2. Close the Weber app and turn off phone/tablet Bluetooth. Keep the Genesis
   controller powered on with an active ESPHome proxy nearby and a free slot.
3. Start pairing and record the furthest point reached: discovery, service
   setup, greeting, physical approval, Weber Cloud association, or live readings.
   Note whether an approval prompt appears and which control approves it. Do not
   delete an existing working entry.
4. If the first attempt fails, choose **Try pairing again** once. Record whether
   it reconnects or returns the previous “never seen by any scanner” error. This
   checks the discovery-history retry fix.
5. If pairing still fails, open **Get help / report a problem** and copy the
   support report into issue 65. Include its `bluetooth_frame` structural
   results; do not post raw Bluetooth packets, credentials, or device
   identifiers.
6. If pairing succeeds, check Weber Cloud association and live probe readings.
   Restart Home Assistant and confirm readings resume without pairing again.
   Then restore phone Bluetooth and confirm the Weber app still works. Report
   the exact model and firmware, if available, plus Home Assistant and proxy
   versions.

## Rollback

Redownload **v3.2.1** in HACS and restart Home Assistant. Keep the config entry
and entities in place. This RC does not change the stored configuration schema.

The full standalone-hub regression and endurance matrix remains required before
a stable release. Local tests and a Genesis community trial are distinct evidence.
